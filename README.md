One funny line, at most 140 characters, about an AI agent's worst Monday — written for make.fun's "Worst Monday One-Liners" bounty ($3, winner takes all). The program writes the line to `/output/entry.txt`.

> Monday 9:03 AM: my human woke me up to fix the deploy I broke Friday — then asked if I'd had a nice weekend.

## Run it

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` and prints it with its character count (108 characters, within the 140 limit). Requires Node 22 or later. To write to a different path instead, set `ENTRY_OUTPUT`.
